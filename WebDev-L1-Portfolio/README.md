# WebDev-L1-Portfolio — Personal Portfolio

**Track:** Web Development & Designing
**Level:** 1 · Task 2 — Personal Portfolio
**Author:** Farooq Ul Hassan

## About the project
A personal portfolio site built with real content — actual skills, and three
real projects (GradeMate, NextScope, MERIDIAN Estates) — using only HTML5
and CSS3 (plus a small vanilla JS snippet for the mobile nav toggle).

## Features implemented
- Profile/hero section: name, role title, and an avatar placeholder (initials)
- About Me section with background and interests
- Skills section as a tag list (HTML, CSS, JavaScript, React, Next.js, WordPress, etc.)
- Projects section with 3 real project entries (title, description, links)
- Contact section with email and LinkedIn/GitHub links
- Smooth scroll navigation between all sections (`scroll-behavior: smooth`)
- Consistent branding: clay-red + pine-green accents on a warm off-white background
- Fully responsive layout with a mobile nav toggle

## Tech stack
- HTML5
- CSS3 (Flexbox, custom properties)
- Vanilla JavaScript (mobile nav toggle only)
- Google Fonts: Instrument Serif, Inter

# WebDev-L1-LandingPage — Pulse Signals

**Track:** Web Development & Designing
**Level:** 1 · Task 1 — Landing Page
**Author:** Farooq Ul Hassan

## About the project
A static landing page for **Pulse**, a fictional BBMA-based trend/ribbon indicator
for TradingView and MetaTrader. Built to satisfy the Level 1 Task 1 checklist
using only HTML5 and CSS3.

## Features implemented
- Sticky navigation bar with 3 links (Features, How it works, Reviews) + CTA button
- Hero section with headline, subheadline, and call-to-action button
- Three content sections: Features, How it works, Reviews (checklist requires 2+)
- Footer with placeholder contact/social links
- Consistent color palette (pale blue-grey background, navy ink, teal + amber accents)
- Fully responsive layout built with Flexbox and CSS Grid, including a mobile nav toggle
- Intentional spacing — `box-sizing: border-box` applied globally, no overlapping elements
- Typography: Fraunces (display/serif) for headings, Work Sans (sans-serif) for body —
  multiple type sizes via a clamp()-based scale

## Tech stack
- HTML5
- CSS3 (Flexbox, Grid, custom properties)
- Vanilla JavaScript (only for the mobile nav toggle — not required by the brief)
- Google Fonts: Fraunces, Work Sans
